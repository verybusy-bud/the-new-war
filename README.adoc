= README for tnw (The New War)

tnw is a multiplayer version of vms-empire, a simulation of full-scale
war between emperors. The object of the game is to conquer all enemies and
become the sole ruler.

This is a multiplayer 4X strategy game supporting both hotseat (local) and
network play. Battle for territory, build armies and fleets, capture cities,
and eliminate your opponents.

== Multiplayer Modes

=== Hotseat Mode (Local)

Run with 2-4 players on the same machine:
./tnw -p 2 # 2 players
./tnw -p 3 # 3 players
./tnw -p 4 # 4 players

Players take turns controlling their forces on the same screen.
Press 'E' to end your turn and pass control to the next player.

=== Network Server Mode

Run as a server to allow remote players to connect:
./tnw --server -p 4 # Server for 4 players
./tnw --server --port 7777 -p 2 # Custom port

The server will wait for all players to connect before starting the game.
Players can connect using any TCP client (e.g., telnet or nc):
telnet <server_ip> 6666

Player Colors:
Player 1: Red Armies
Player 2: Yellow Armies
Player 3: Purple Armies
Player 4: White Armies

== Building

make clean && make

Requires: ncurses

== Multi-User Server Architecture (New)

This codebase now includes a three-tier architecture for multi-user gameplay
similar to Wolfpack Empire:

=== Architecture Components

1. **empire_frontend** - Telnet frontend accepting connections on port 5000
2. **empire_server** - Authoritative game server (port 4000 or Unix socket)
3. **empire_client** - Per-session terminal client

=== Quick Start

```bash
# Build all components
make clean && make

# Setup directories and user (run as root)
sudo ./setup.sh

# Install binaries
sudo cp empire_server empire_frontend /usr/local/bin/

# Start services manually
./empire_server -d
./empire_frontend -d

# Connect with telnet
telnet localhost 5000
```

=== Systemd Deployment

```bash
# Install service files
sudo cp empire-server.service empire-frontend.service /etc/systemd/system/
sudo systemctl daemon-reload
sudo systemctl enable --now empire-server empire-frontend
```

See ARCHITECTURE.md for complete documentation.
