WeGo Simultaneous Turns

  • Planning Phase: Both players secretly give orders to their units
  • Orders: Select a unit, choose order type, then define the action
  • Move: Click multiple cells to draw a path - unit will follow it
  • Seek: Unit automatically finds and charges nearest enemy
  • Shoot: Select target - unit fires if in range and arc
  • Fire & Advance: Infantry moves 25% slower but fires while moving
  • Fallback: Retreat 30% slower, face away, fire at pursuers
  • Execution: Click "Execute Turn" - both sides act simultaneously!
  • Win: Capture enemy base or control most objectives
